# 画境场景精细化

用户反馈：第一版物件粗糙、素材使用少、环境空、与五张成品图差距大，人物高浮雕过于抽象。本轮以重建场景、替换主体展件为范围，不更换已经可用的找画 / 固定对齐 / 入画 / 钥匙开门规则。

## 展件替代方案

五件原作都完整保留画面、衬底及原始画框的正面图像。只按整个外框的矩形边界取 UV，不提取人物、花朵、动物的轮廓。增加实体木背板、侧壁、分层外框线与合比例基座，替换旧人物高浮雕。原始 JPEG 文件保持原样，信息窗明确称为带框展示模型，不声称是人物雕塑或藏品扫描。

展件位置重新纳入场景构图：庭院与宫廷分置左侧，其余沿中轴后退，避免近处大画框遮住大部分场景。视野相应扩大；所有入画窗口、穿越动画和主相机使用一致的投影参数。

## 环境模型

- 青花庭院：开敞回廊、车制栏杆、桥面砌块及弧形扶手、花池岸石、空心瓷器及耳柄、曲面花瓣与花叶、藤蔓、灯架、池水。移除封闭房间式的布局。
- 哥特教堂：分块尖拱券、连续砌体、交叉拱顶、带窗棂的原素材彩窗、木质长椅及雕饰、烛台、书案、侧祭坛、雕刻石板。通路留在中轴及长椅两侧。
- 金色沙龙：有织纹密度控制的红色壁面、带真实褶皱的窗帘、分层烛式吊灯与切面垂饰、弯腿控制台、软包椅、原素材装框肖像、花器、浑仪、细密织纹地毯与流苏。
- 晨光圣殿：石质拱顶、分层墙面、彩窗、太阳光环及放射线、带框石雕装饰、祭案、烛台、花器、浑仪与光束。舍弃失真的简易人形代理雕像。
- 蓝金宫廷：洋葱形穹顶及金属经线、蓝金墙面、瓷器立柱、花格与挂灯、棕榈、空心分层喷泉、灯具、花器和钥匙祭台。舍弃粗糙的简易动物代理模型。

模型以可编辑零件保存在 `.blend` 中；游戏导出按材质合并，以减少绘制批次。曲线饰条改用适合曲线的实色材质，避免长度 UV 采样到集合图的邻格。立柱 UV 按实际高度分配并重复，避免把很窄的纹样拉成长条。花叶不保留重复反面导致的法线抵消。

## 素材来源与补充纹理

继续使用用户文件夹中的五组原始集合图，彩窗、雕刻板、肖像等按所属空间使用。它们没有被直接作为整张场景背景。

`environment-assets/painting-worlds/refinement/material-atlas-v2.png` 是本轮通过内置 image_gen 工具生成的环境补充材质，不是博物馆照片，不替代原作。参考输入为用户的第 1、3、5 组集合图。实际输出 **1254 × 1254** 像素，16 个材质区域；通过按实际尺寸重复 UV 使用，不能称为 4K 成品。

生成提示词摘要：精确 4×4 无间隙平面材质图集，中性漫反射，依次为青花花卉、象牙大理石、石砌块、旧金、酒红织锦、胡桃木、蓝金大理石、钴蓝金格、波斯星纹、浅金卷草、红地毯、青花百合燕子、石刻卷草、蓝色菱格玻璃、金色卷草、浅色八角砖。要求清晰细节，无标签、无场景、无透视、无水印。工具实际生成结果完整保留在上述路径。

## 模型目录与重建

```sh
blender --background --factory-startup --python-exit-code 1 --python blender/scripts/refine_painting_worlds.py
blender --background --factory-startup --python-exit-code 1 --python blender/scripts/refine_painting_props.py
```

新资源使用 `painting-worlds-v2` 独立目录，避免旧模型缓存混入。

- `blender/blend/painting-worlds-v2/world-1.blend` 至 `world-5.blend`：新场景及完整带框展件。
- 同目录 `portal-frame.blend`、`lectern.blend`、`key.blend`：公共交互展件；画框和车制阅读台已重制，钥匙沿用已正常工作的独立模型。
- `public/models/painting-worlds-v2/room-1.glb` 至 `room-5.glb`：新场景。
- 同目录 `artwork-1.glb` 至 `artwork-5.glb`：完整带框原作。
- 同目录 `portal-frame.glb`、`lectern.glb`、`key.glb`：公共模型。
- `environment-assets/painting-worlds/refinement/model-manifest.json`：实际生成后的零件、批次和顶点统计。

较复杂的模型使用 Draco 压缩，解码器随网站部署到 `public/draco/`，不依赖外部解码 CDN；原始 `.blend` 不做网格压缩。第三方说明与许可在同目录保留。旧模型目录作为历史资源留存，不再被当前第三章加载。

## 本轮验证

类型检查、57 项自动测试和生产构建通过。隔离测试档实际完成第二关入口、五个画境、四次对齐入画、钥匙、最终门、刷新及重新探索。另验证真实触摸事件下的摇杆移动、双指分工转向、释放停止，以及 390×844、844×390、1024×768、768×1024、320×568 的中韩英关键 UI 排版。WebKit 触屏上下文验证摇杆和原作信息窗通过。

五个 `.blend` 场景合计保留 14,515 个可编辑对象，运行时按材质合并为每场景 10–22 个批次；详细数字见模型清单。这是结构与陈设的重建统计，不用对象数代替视觉质量判断。

实时时间点截图保存在 `docs/previews/painting-v2/`；这些是实际网页渲染画面，不是用户的成品参考图。游戏交互关键结果记录在 `docs/PAINTING_REFINEMENT_VALIDATION.json`。

## 验证边界

资产测试检查完整画框、真实网格、Draco 交付及缓存目录。Three.js 主渲染依赖保留大体积包的构建提示；运行时按当前与下一画境加载模型，离开后释放未使用的资源。

这些成品参考是高质量预渲染图；本轮以实时 3D 几何、相同材质语言、陈设构图、灯光层次向其靠近，不声称网页实时画面已与离线渲染逐像素一致。真实移动设备表现仍需用户体验反馈，自动化浏览器检查不能代替全部真实机型。
