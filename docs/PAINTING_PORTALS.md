# 画境之间的连续双向通道

2026-11-15。第三章五个画境之间改为摄像机实际穿越，不提供回退按钮。第二章至第三章的原入口和最终之门流程保留。

## 操作

找到并对齐放置下一幅画后，画框内呈现目标空间，直接用 WASD／方向键或触屏摇杆走过去。进入后回头，入口画框显示上一个空间，走回去即可返回；保持朝向、倒退着穿过也可以。重复往返不清除画作、摆放状态、钥匙或图鉴，不增加分数。

## 渲染与准备

- 使用实际目标场景的离屏实时渲染。窗口随摄像机平移和转向产生透视变化，不是视频或固定相机截图。
- 全屏投影采样保持贴近窗口时的清晰度；斜近裁剪排除入口外侧墙壁，避免透视中出现房间外墙。
- 在当前画境加载时准备前后相邻场景；实际渲染目标场景数帧后才允许穿越。慢网络下保留原画和当前场景，准备完成后展开窗口，不在穿越时展示下载／生成页面。
- 穿越检测位于画框开口及平面附近。按两框之间的空间关系换算位置，保留水平偏移、朝向和俯仰；没有原来的2.25秒放大全屏过场和重置出生点。
- 主场景与窗口共用可拾取画作／钥匙的组件，减少交接时道具突然出现。窗口不递归渲染更多画框。
- 活跃场景范围为当前、上一和下一画境；只更新视野中的实时窗口，其他窗口预热后停止渲染。模型延续既有引用计数和延迟释放机制，避免把五个完整场景长期全部常驻。
- 初次进入或刷新网页仍需正常获取模型，无法让尚未下载的资源凭空出现；这与画境之间已准备好的连续穿越不同。

## 进度兼容

旧存档可以继续使用。存档读取不再因返回较早画境而截断未来已经找到／摆放的作品；已取得的最终钥匙也保留。完整探索后返回第三或第四画境、刷新网页，再进入第五画境仍可使用钥匙。重新探索会正常清空第三章的探索状态，保留其他章节与收藏。

- 类型检查、65项自动测试、GitHub Pages基础路径的生产构建通过。
- 新测试覆盖开口边界、正向／倒退穿越、摄像机坐标与透视连续性、外墙裁剪、往返与存档、钥匙保留和不计分。
