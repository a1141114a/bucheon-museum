## 当前边界

- 这是第一关可玩练习版，尚未替换为经用户审核的真实文物；没有使用任何真实馆藏照片。
- 交互采用“选择碎片 → 90° 旋转 → 选择位置”，不是物理自由拖拽模拟。三维对象和按钮均可选择，按钮提供键盘/手机操作替代。
- 第一关完成状态已写入存档；后两关仍显示开发中，不会跳入不存在的玩法。
- 没有云同步或防作弊保证；分数由本机进度重新计算，不信任存档中的总分。
- 真实手机多指触控、低端移动 GPU 性能尚未实机验收。
- Three.js（约 704 kB）及渲染分包（增加轮廓线后约 522 kB）仍有 Vite 体积提示；未隐藏警告。
- Blender 有面向 6.0 的 `Material.use_nodes` 弃用提示；本次实际执行版本 5.2.3 正常完成导出和回读。
- GitHub Pages 子路径在本地生产预览验证，尚未推送或远程部署。
