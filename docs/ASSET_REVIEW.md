# 真实文物资料与审核流程

用户约束：游戏文物素材必须先由用户审核，通过后才能建模和使用。当前真实文物获批数量为 **0**。技术测试形体不是馆藏复原，无藏品照片。

## 当前资料状态（2026-11-04）

已访问以下官方入口，仅用于下一阶段资料搜集：

- [官方藏品](https://www.bcmuseum.or.kr/ko/collection/)
- [官方图录](https://www.bcmuseum.or.kr/ko/book/)
- [常设展览](https://www.bcmuseum.or.kr/ko/pages/exhi_permanent)

常设展览入口可确认有瓮器、乡土历史、欧洲瓷器及教育等展区。**展区名称不能证明某一件文物的具体名称、年代、材质或照片许可。** 本阶段没有建立任何“已核实真实藏品”记录，也未下载或发布馆方照片。

## 下一阶段目标

整理 6–9 件候选文物，优先覆盖瓮器、欧洲瓷器、乡土历史和教育史。此处只定义搜集范围，不虚构具体名称或登记号。

每件候选必须提交以下资料供用户审核：

| 字段 | 要求 |
|---|---|
| 具体名称 | 官方韩文原名；中文及英文译名须标明译名待审 |
| 出处 | 博物馆、登记号（若可查）、逐件官方详情 URL |
| 描述 | 年代、材质、用途、历史；逐项记录出处；缺失标记“待核实” |
| 照片 | 原图来源 URL、摄影/权利署名、许可条款或授权证明；不把网页可访问当成授权 |
| 建模参考 | 尺寸、多角度参考、不可见部位的不确定性 |
| 用户审核 | pending / approved / rejected；结论日期及会话或审核文件证据 |
| 接入范围 | 关卡、信息卡、图鉴和可公开的素材范围 |

必须先完成逐件核实并取得用户明确审核通过，再开始对应真实文物建模。照片还需另行取得可公开使用的许可。审批状态和图片许可分别记录，不能相互代替。

数据接口见 `src/types.ts`。`canModelCollection()` 检查核实及用户审核状态；`canPublishPhoto()` 进一步检查照片来源及许可证据。当前未实现真实藏品模型加载，后续接入时也必须调用相同审核规则。

## 模型交付约定

- `blender/scripts/<artifact-id>.py`：可重复建模脚本。
- `blender/blend/<artifact-id>.blend`：可编辑源文件，保留结构与材质。
- `public/models/<artifact-id>.glb`：游戏模型，采用米、glTF Y-up。
- 建模前注明“参考复原”与不确定部分；不得暗示博物馆官方认证。
- 对应照片有许可后才存入 `public/photos/`；未授权参考资料留在审核流程内，不进入公开构建目录。
