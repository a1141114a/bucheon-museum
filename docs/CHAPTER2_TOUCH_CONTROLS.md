# 第二关：点击金币与触屏摇杆

- 金币只有在靠近且视线未被展柜底座阻挡时，点击实际 3D 金币才能收取。
- 靠近不自动收取；移除独立的“拾取金币”界面按钮。
- 旋转视角时的拖动不会触发金币、宝箱或展品的点击。
- 保留三枚金币的尺寸和隐藏位置，为触摸点击提供不可见的小范围命中辅助。
- 手机及 iPad 使用左下模拟摇杆移动，拖动画面观察，可同时使用两个手指。
- 根据触摸能力识别设备，兼容 iPad 桌面浏览模式；电脑保留键盘和方向按钮。
- 摇杆带死区、模拟速度和圆形限位，松手、取消触摸、失焦、切换后台、
  窗口尺寸变化或打开拼图/名片后归零，继续游戏不会沿用旧输入。
- 任务面板在触屏上限制高度并可滚动，避免遮挡摇杆。
- 返回入口、重玩关卡时摇杆与摄像机一起复位。

## 验证

52 项单元测试通过，包含摇杆死区、四方向、模拟速度及对角速度限位。
在独立本地测试档中，用 Chromium 触摸事件验证了移动、双指转视角、
松手/取消/失焦/拼图暂停停止，以及三枚金币实际点击收取。
验证远距离点击拒绝、靠近不自动收取、拖动不拾取、金币消失及宝箱拼图入口。
检查中韩英三种语言的手机横竖屏和 iPad 尺寸，保留原收藏卡片收录操作。
WebKit 下验证摇杆移动与停止，桌面键盘移动正常，未改动用户进度。
