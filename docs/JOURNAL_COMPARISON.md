# 图鉴：原图与 3D 对照分区

新增独立分区，直接展示已发现或已收录藏品的官方照片、可旋转 3D 模型、
中韩英名称、收藏机构、年代、材质、尺寸、用途、历史与来源。
原收藏卡片及未解锁状态保留。对照分区仅供浏览，不提供收录按钮；
收录操作仍在原收藏卡片中进行，积分仍由原有规则处理。

## 照片

用户于 2026-11-13 明确要求同时展示官方原图并保留官方照片入口。
仅引用经过核实、用户批准藏品条目中的官方外部图片，不复制或改写版权许可。
图片信用署名及来源链接直接显示，photo.rights 保持 pending，并如实标注。
原有 canPublishPhoto 和卡片图片规则不变。

高清接口失效时，仅回退到元数据中已有的官方展示图片 URL。
例如 bcm-929 的高清接口返回 404，而同一馆方条目的展示图仍可访问。
两者均失败时保留官方入口及明确的无法加载提示，不以模型图冒充实物照片。

## 实时 3D

滚动进入视野即自动加载真实 GLB，最多同时保留两处实时 WebGL 视图。
离屏行显示已有模型渲染图。模型加载完成后切换到实时视图，避免闪白。
禁用内嵌模型的滚轮缩放，并允许手机纵向滚动、横向旋转，减少页面滚动干涉。
不支持 WebGL 时保留模型渲染图并显示错误说明，其他资料照常可读。
原独立模型查看器的缩放操作保留。

## 检查

验证了 12 件官方照片（含馆方展示图回退）、真实模型旋转、滚动切换、
最多两处实时视图、直接收录、原卡片分区和未解锁图片隐藏。
在 Chromium 与 WebKit 两种引擎及中韩英三种语言下检查桌面、iPad、
手机横竖屏；未改动用户存档。
