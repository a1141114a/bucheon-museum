# 现代厅开场与第三章入口修复

日期：2026-11-25。

## 现在的游玩流程

首页“开始游戏” → `/museum`现代富川市立博物馆，可键盘／摇杆走动、拖动转向和查看藏品 → 走近展厅尽端空白墙面 → 自动出现时光裂隙并吸入 → 完整四格漫画 → 点击开始冒险 → 第一关 → 第二关画作入口 → 第一幅画境 → 五个画境与最终门 → 现代博物馆结尾。

现代厅共用同一真实3D模型，使用独立的intro／ending模式。开场没有结局文字或旅途回顾；结尾不启用开场传送门。二者的路由和触发条件不会互相替代。

点击首页开始不会立刻清掉旧进度；在看完漫画并点击开始冒险时，以journey-start开启新一轮关卡，保留已收藏藏品和语言，清空本轮修复、金币与画境进度，并进入可玩的第一关。直接通过章节菜单访问关卡仍可继续原存档。原存档版本及键名保持兼容。

## 传送门素材接口

`src/state/museumJourney.ts`记录触发范围：传送门位于x=-1.65、y=1.44、z=-6.22的尽端空白墙面；玩家在可行走过道靠近该墙面2.9米内自动触发。

`MuseumPortal.tsx`使用用户本轮提供的720×752、约6秒MP4传送门素材，静音、内联播放并循环；视频原始字节不修改，通过首帧连通背景蒙版和着色器去除编码在画面里的黑灰棋盘格背景，保留门框与旋涡。reveal约0.85秒，pulling约1.55秒，自动向墙内移动摄像机并平滑转向，随后显示用户提供的1536×1024四格漫画；点击中／韩／英“开始冒险”按钮后才进入第一关；没有新增文物或使用未经审核的照片。`IntroComic.tsx`用原比例contain展示完整图片，按钮和文字位于图片外部，手机和平板不裁切分镜；加载失败可重试或继续。两份素材及原始SHA-256见`public/ui/journey/manifest.json`。

菜单／藏品卡片打开时暂停行走与触发。吸入开始后锁定行走，避免摄像机被两个控制器争用；收起页面时不按大时间差跳过过场。减少动态效果偏好下取消摄像机转向、推近和视频自动播放，保留轻柔淡入与相同目标关卡。

## 修复的旧存档问题

原photo-start只把entered改成true，保留room=4、key=true、finished=true等旧完成状态。因此从第二关再次进入画作，会被PhotoChamber识别为已经完成，直接显示终点现代厅。

现在显式的第二关画作入口photo-start始终初始化第一幅画境；保留普通章节访问／刷新时的存档恢复行为。第二关重新开始时也清除下游画境完成状态，防止本轮金币未完成却保留第三章通关标记。photo-finish仍只允许第五画境持有钥匙且靠近最终门时完成。

## 开场引导、自动拼合与金币光提示

现代厅有默认展开、可收纳的两步指引；方向箭头依据当前相机朝向实时更新，显示下一个引导点距离。先沿可走动的过道前进，再转向尽端左侧墙面，避免箭头把玩家直接带入中央展柜。传送出现后隐藏普通提示窗，保留沉浸式画面，漫画阶段使用原生模态框完整展示图片。

第一关取消两个碎片旋转按钮及Q/E碎片旋转快捷键；位置身份匹配即可拼合，状态中同步记录角度0，场景平滑移动并转正。错误位置仍拒绝，旧存档中的任意旋转值不影响正确拼合；提示不再要求旋转次数，教程同步为两步。原积分、提示扣分、完成光效与结算保留。

三枚金币继续藏在原来角落的展品后方，不移动、不自动拾取。根据玩家水平距离平滑增强外圈光晕、轻微暖光和材质微光；9米外很弱，1米内最亮，范围有上限。光晕中心完全透明，表面自发光最高0.16，避免把浮雕和纹样冲成白块。精确收取距离与视线遮挡规则保持，必须靠近后点击；收取后该枚金币及光效一并移除。三枚独立材质不影响宝箱喷出的金币或其他展品。

Chromium/WebKit均以真实网格点击完成九块无旋转修复；三枚金币均检查远弱近强、光晕中心透明、不自动收取、点击后移除，未出现页面或着色器错误。验证报告在同目录JSON。
