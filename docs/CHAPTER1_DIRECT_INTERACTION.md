# 第一关：直接点击修复

- 点击桌上的 3D 碎片选中，选中碎片悬浮并显示金色轮廓。
- 下方仅保留左转和右转两个按钮；仍支持 Q / E。
- 点击器物虚影的对应区域尝试拼合，保留位置与旋转方向校验。
- 移除下方字母碎片列表、数字位置列表和原大型碎片匣面板。
- 场景中的小型字母、位置编号继续辅助辨认与提示；拼合后编号按原规则消失。
- 完成动画、动态结算卡片、积分、提示、进度保存及章节解锁保持原流程。
- 查看结算入口移至左上进度提示区，底部不增加其他按钮。

## 验证

- TypeScript 检查、生产构建和 45 项单元测试通过。
- 独立浏览器测试存档下，桌面 Chromium 和手机尺寸 WebKit 均通过真实 3D 网格点击完成九块修复。
- 验证错误位置、错误方向提示，两个旋转按钮、结算关闭与重新查看，以及刷新续玩。
- iPad 1024×768、手机横屏 844×390 通过实际碎片和虚影点击。
- 中、韩、英三种语言在 320×568、390×844、844×390、768×1024、1024×768、1280×900 共 18 组排版检查通过。
- 测试使用独立临时存档和仅在本地测试响应注入的场景读取钩子，不包含在发布代码中，也未改动用户进度。
