# 第三章：画境之门

本文记录首次接入时的实现。现行完整带框展件和重建环境以 [场景精细化记录](PAINTING_REFINEMENT.md) 为准。

2026-11-14。正式替换旧时间齿轮玩法；不发布独立测试版。

## 用户确认的流程

第二章宝箱完成后，后墙原作发光。玩家靠近后进入第一画境。在前四个画境寻找下一幅画作，携带至固定金色观察标记，面向预设画框举起、对齐并放置。画框内由原作渐变为真实三维空间：前方是匹配原作构图的立体展品，后方是对应环境。走近画框继续向前，窗口扩展为下一空间。第五画境找钥匙开最终门，结束游戏。

无时间、次数及分数规则；不能随处放画或改造任意空间。可保存、继续、单独重新探索第三章。旧齿轮关通关不能跳过新流程。

## 模型与渲染

- Blender 5.2.3 LTS 后台实际生成 8 个 `.blend`、13 个 `.glb`、2 个脚本。
- 所有房间由立体地面、墙体、立柱、拱券、桥、家具、灯具等模型组成；不把环境参考图当作整张背景。
- 材质取自用户原始集合图的指定 UV 区域。UV 变换直接烘入网格，避免 Blender 节点图在 glTF 导出中丢失。
- 原作主体为闭合高浮雕；通过逆透视投影保持原作正面构图，具有实体边缘与背面。背面及深度为推定，不能称为实物扫描或完整精密圆雕。原作信息窗明确说明。
- 当前房间和相邻房间窗口实时渲染。窗口中实际加载目的地 GLB，不使用视频或目标场景截图。
- 进入时，目的地相机的纵横比与窗口扩大同步，最后与主相机一致。竖屏扩大纵向视场，避免横向强裁切。
- 画框、画架、钥匙单独建模。最终门两扇模型分别保留枢轴组，开门后出现金色光源与结尾界面。
- 离开场景后延迟释放未再使用的几何体、材质、纹理和加载缓存；延迟允许跨门时复用已预热资源。
