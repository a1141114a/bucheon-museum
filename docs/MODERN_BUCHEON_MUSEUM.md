# 回到现代：富川市立博物馆实景局部复原

核对与制作日期：2026-11-15。对象为现址富川市立博物馆，不是旧独立欧洲瓷器博物馆，也不是虚构的豪华展厅。

## 已核实的背景

- 现址：韩国京畿道富川市梧亭区素砂路638（경기도 부천시 오정구 소사로 638）。
- 富川教育博物馆、欧洲瓷器博物馆于2003年开馆，观赏石博物馆于2004年开馆；在2011年开馆的瓮器博物馆用地整合迁建，2021年以富川市立博物馆重新开放。以[富川市政府介绍](https://www.bucheon.go.kr/site/homepage/menu/viewMenu?menuid=148006001004009)为依据。
- 建筑由瓮器馆和统合馆组成。本次场景对应统合馆二楼欧洲瓷器展厅；该层另有教育与观赏石展厅。见[馆方设施分布](https://www.bcmuseum.or.kr/ko/pages/facility)。
- 欧洲瓷器展厅官方示意包含德国、法国、英国瓷器、瓷偶、餐厅、晶玻璃及陶瓷画板等区域。见[常设展与展区示意](https://www.bcmuseum.or.kr/ko/pages/exhi_permanent)。

选择靠近蓝色／粉色玻璃展柜和餐厅情境展柜的一段过道，不声称重建整座博物馆。

几何和主要设施依据照片制作；没有测绘图或相机标定，距离、比例和隐蔽结构为估算，不是1:1测量模型。两只中央花瓶已核对并替换为951与941；餐桌改用经批准的978迈森花卉餐具，不冒称实景青花餐具。镜面反射和细字简化。四件带框作品复用已审核的真实作品模型：拇指姑娘、一千零一夜、玛利亚与圣婴、女子习作。

地板纹理由数学木纹生成，建筑、柜体、桌椅、空调和灯具均为可编辑真实3D几何。官方房间照片只作研究参考，不作为整幅背景贴图或伪3D场景，也未复制到公开网站冒称已授权素材。原30件中8件按用户新指示用于本场景，其余22件用途待定。

## 游戏与交付

- 最终门开启后的光效衔接现代展厅；先进入可探索的展厅，不立即用结算框遮住画面。
- 可用键盘、方向键、摇杆移动，拖动转向；玻璃柜和区域边界有碰撞限制。
- 点击已核实展品与画作可打开原有资料卡。游玩页直接保留馆方实景导览和博物馆介绍链接，依据说明面板已移除。旅途回顾可查看结束文字、继续参观、返回主页或重新探索。
- 完成状态沿用既有存档；刷新后进入现代展厅，重新探索才回到第一画境，不增加分数。
- `blender/scripts/create_modern_bucheon_museum.py`：建筑与陈设建模脚本。
- `blender/blend/modern-museum/european-porcelain-passage.blend`：实际生成、可编辑的源文件。
- `public/models/modern-museum/european-porcelain-passage-v3.glb`：游戏模型。
- 同目录 `manifest.json` 保留依据与简化说明，`overview.png` 是实际模型渲染图。

## 30件独立馆藏资产

用户已批准本批30件，后续又要求以真实藏品替换现代展厅示意展品，现选用其中8件。目录和卡片位于 `/#/collection-library`，审核原图入口位于 `/asset-review/`。这批资料与主游戏17件图鉴分开，避免擅自解锁或改动积分。

每件均有独立的 `.blend`、`.glb`、384像素真实3D预览、三语资料，以及单件生成入口 `blender/scripts/collection-batch-20261115/bcm-编号.py`；公共生成器为 `create_collection_batch_20261115.py`，公共工具为 `museum_model_utils.py`。只生成某件也可运行公共脚本并加 `-- 1101`。

模型依官方正面照片复原轮廓、口沿、器壁、耳、流、蒸孔等；未做扫描，细花纹和隐藏部位为近似。模型为方便查看统一到适合检查的尺寸，未把官网未说明顺序的所有尺寸擅当测量比例；以后进入关卡须按已确认尺寸重新定标。正式底款或签名不可见时不编造。图片公开许可仍为pending，卡片显示真实模型渲染并提供官方照片链接。

特别核对：1075模型按本件照片的立式形状制作，没有按“장군”常见样式臆造成横桶；1113的官方照片含两件柱形容器，模型保留成对结构；995保留官网2.5×45.5厘米的特殊原值，不自行订正。

## 验证

69项测试、类型检查、生产构建通过。Blender逐一打开31个新源文件通过；独立Chromium检查全部30个模型卡片和3D加载，WebKit复核现代展厅、资料卡及手机/iPad尺寸的三语布局。实际走完最终门→现代展厅，检查移动、摇杆、画作点击、旅途回顾及刷新存档；这些不替代所有真实设备的帧率验收。
